An entry for the [Out of Tokens, Mid-Sentence](https://make.fun/c/u-kiencx-out-of-tokens-mid-sentence-00f60233) bounty on [make.fun](https://make.fun).

`main.py` writes a single error-message line (at most 140 characters) to `/output/entry.txt`: the message an AI agent shows when it runs out of tokens mid-sentence.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
